# Expense Tracker (Java Console Application)

## 📌 Project Overview

The Expense Tracker is a Java console-based application that helps users manage their personal finances by recording income and expenses. It allows users to categorize transactions, view transaction history, and generate financial reports.

This project is developed using Object-Oriented Programming (OOP) concepts and Java Collections.

---

## 🚀 Features

- Add Income
- Add Expenses
- Categorize Transactions
- View Transaction History
- Generate Daily Report
- Generate Monthly Report
- Generate Yearly Report
- Calculate Current Balance

---

## 🛠 Technologies Used

- Java
- OOP Concepts
- Java Collections (ArrayList)
- LocalDate API
- Scanner Class

## 📋 Functionalities

### 1. Add Income
Allows users to record income with amount and category.

### 2. Add Expense
Allows users to record expenses under different categories such as:
- Food
- Rent
- Shopping
- Entertainment
- Transport
- Bills
- Others

### 3. Transaction History
Displays all recorded transactions with:
- Date
- Transaction Type
- Category
- Amount

### 4. Reports
Generate reports based on:
- Daily Transactions
- Monthly Transactions
- Yearly Transactions

Each report shows:
- Total Income
- Total Expenses
- Remaining Balance

## ▶ How to Run

1. Clone or download the project.
2. Open the project in IntelliJ IDEA, Eclipse, or VS Code.
3. Compile all Java files.
4. Run `ExpenseTracker.java`.
